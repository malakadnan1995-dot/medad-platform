# المنصة التعليمية التفاعلية — مِداد

تطبيق تعليمي عربي باتجاه RTL، يضم مساراً عملياً كاملاً في مهارات التعلّم الرقمي، فهرساً تفاعلياً، اختبارات اختيار من متعدد، حفظاً محلياً للتقدم، وقارئاً صوتياً لكل صفحة.

## التشغيل

المتطلبات: Node.js 18.11 أو أحدث. لا توجد مكتبات خارجية مطلوبة.

```bash
npm start
```

افتح `http://localhost:3000` في المتصفح. أثناء التطوير استخدم `npm run dev` لإعادة تشغيل الخادم تلقائياً عند تعديل ملف الخادم. يمكن تشغيل التطبيق أيضاً عبر خادم ملفات ثابتة يخدم مجلد المشروع، على أن يوجّه مسار `/audio/*` إلى `public/audio/` ويضبط نوع MIME لملفات الصوت.

شغّل `npm test` لفحص بنية المنهج، اكتمال الأسئلة، ووجود كل ملفات الصوت ومسارات الصفحات.

## محتويات المشروع

- `index.html`: صفحة الدخول العربية وبيانات الصفحة.
- `styles.css`: التصميم المتجاوب، دعم RTL والوضع الداكن.
- `src/app.js`: التنقل والفهرس والاختبار والنتيجة والتقدم.
- `src/curriculum.js`: وحدات المنهج ودروسه ومحتوى الأسئلة؛ هذا هو الملف الرئيسي لإضافة المحتوى.
- `src/voice.js`: قارئ الصوت، مؤثرات الإجابات ورفع الصوت الشخصي.
- `server.mjs`: خادم ملفات بسيط دون اعتماديات، ويقدّم تسجيلات `/audio/` من `public/audio/`.
- `assets/`: الشعار والمخطط التعليمي.
- `public/audio/`: الصوت العربي المولّد والمضغوط بصيغة MP3 للدروس وصفحة البداية وأسئلة الاختبار.
- `TODO.md`: معايير الإنجاز للمشروع.

## إضافة درس أو سؤال

أضف الوحدة أو الدرس في `curriculum.modules` في `src/curriculum.js`. لكل درس معرّف فريد، وعنوان وملخص ومدة ومصفوفة `blocks`. الأنواع المدعومة: `lead`, `heading`, `paragraph`, `list`, `steps`, `figure`, `callout`. استخدم مسار صورة نسبياً مثل `/assets/example.svg`. أضف سؤال الاختيار المتعدد إلى `curriculum.quiz` مع أربعة خيارات وموضع الإجابة الصحيحة (الفهرس يبدأ من صفر) وشرح للإجابة. يحدّث التطبيق أعداد الدروس والأسئلة تلقائياً. لتوفير قراءة آلية أصلية لمحتوى جديد، أضف ملف MP3 إلى `public/audio/` بالاسم المتوافق مع معرّف الدرس (`lesson-id.mp3`) أو السؤال (`quiz-N.mp3`)؛ إذا لم يوجد الملف، يستخدم التطبيق قارئ الصوت العربي المتاح على جهاز المستخدم.

## التقدم والصوت الشخصي

تُحفظ الدروس المكتملة، والاختيارات غير المؤكدة، والإجابات المؤكدة، والوضع اللوني في `localStorage`. تُحفظ ملفات الصوت التي يرفعها المستخدم في `IndexedDB` في المتصفح والجهاز الحاليين فقط؛ لا ترفعها المنصة إلى خادم. يقبل مشغل الصفحة ملفات الصوت الشائعة حتى ٥٠ ميغابايت، ويمكن استعادة التسجيل الآلي أو تسجيل الجهاز من الزر نفسه. أُوقف الانتقال التلقائي افتراضياً؛ عند تفعيله ينتظر التطبيق نهاية الصوت قبل متابعة الدرس، وفي الاختبار لا يتخطى سؤالاً لم تؤكد إجابته. يتطلب الصوت على الجهاز دعماً عربياً في قارئ النظام.

القراءات المرفقة مولّدة بصوت تعليمي عربي فصيح. خدمة التوليد المتاحة تتضمن العربية الفصحى والعربية المصرية، ولم يظهر صوت أردني في كتالوج اللهجات المتاح؛ لذلك لم تُنسب اللهجة الأردنية إلى التسجيلات. يستطيع المتعلم استبدال القراءة بتسجيل أردني يرفعه بنفسه.

## بيانات الاختبار محلياً

التطبيق لا يستخدم حسابات أو قاعدة بيانات أو يرسل الإجابات إلى خادم؛ بيانات التعلم تبقى في متصفح المستخدم. زر «إعادة ضبط التقدم» يمسح التقدم وإجابات الاختبار لهذا الجهاز بعد طلب التأكيد.
